# Blockchain Cheque Verification System

A blockchain-integrated cheque verification system developed using Flask, SHA-256 hashing, Web3.py, and Ganache blockchain.

---

## 🚀 Features

- Cheque Registration
- SHA-256 Hash Generation
- Blockchain Hash Storage
- Blockchain-Based Verification
- Tampering Detection
- Verification Logs
- Dashboard Analytics
- Error Handling
- Professional UI

---

## 🛠️ Technologies Used

- Python
- Flask
- HTML/CSS
- PDFPlumber
- SHA-256
- Web3.py
- Ganache Blockchain

---

## 🔗 Project Workflow

1. Upload Original Cheque
2. Extract PDF Text
3. Generate SHA-256 Hash
4. Store Hash on Blockchain
5. Save Blockchain Transaction Hash
6. Upload Cheque for Verification
7. Fetch Original Hash from Blockchain
8. Compare Hashes
9. Detect Tampering

---

## ⚠️ Current Limitations

- Supports text-based PDFs only
- Does not support handwritten cheque recognition
- Ganache blockchain resets on restart

## ▶️ How to Run

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run Ganache Blockchain

Start Ganache before running the application.

### Start Flask App

```bash
python app.py
```

### Open Browser

```text
http://127.0.0.1:5000
```
